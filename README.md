# Pulso — Comunidade Esportiva

O Pulso é uma plataforma de comunidade esportiva desenvolvida para conectar pessoas que praticam diferentes modalidades físicas. A proposta é permitir que os usuários compartilhem suas atividades, acompanhem sua evolução e interajam com outros praticantes em um único ambiente.

O projeto foi desenvolvido como MVP para o desafio da DIO, utilizando inteligência artificial como apoio à concepção e ao desenvolvimento da solução.

## Aplicação

**Acesse:** https://pulso12.lovable.app

## Problema identificado

Pessoas que praticam atividades físicas nem sempre encontram um ambiente que reúna acompanhamento de atividades e interação com outros praticantes de diferentes modalidades.

Muitas plataformas são direcionadas a modalidades específicas ou priorizam apenas o acompanhamento individual de desempenho.

O Pulso busca oferecer uma experiência que coloque a comunidade esportiva no centro, aproximando pessoas com interesses semelhantes.

## Proposta de valor

Uma plataforma que conecta praticantes de diferentes modalidades esportivas, permitindo registrar atividades, compartilhar conquistas, acompanhar a evolução pessoal e interagir com uma comunidade.

## Público-alvo

- Pessoas que praticam musculação.
- Corredores e ciclistas.
- Praticantes de esportes coletivos.
- Pessoas interessadas em atividades físicas e comunidades esportivas.

O público inicial considerado é composto principalmente por jovens e adultos que utilizam tecnologia no acompanhamento de suas atividades.

## Análise de mercado — TAM, SAM e SOM

Para estruturar a oportunidade de mercado, foram utilizadas estimativas preliminares:

| Indicador | Estimativa | Interpretação |
|---|---:|---|
| TAM | 48 milhões | Universo potencial de adultos fisicamente ativos no Brasil, utilizado como aproximação inicial. |
| SAM | 4,8 milhões | Recorte hipotético de 10% do TAM, representando pessoas potencialmente interessadas em uma plataforma comunitária digital. |
| SOM | 500 usuários | Meta inicial de usuários para uma primeira etapa de operação. |

**Observação:** os valores são estimativas de planejamento, não uma medição comprovada do mercado consumidor do Pulso. O SAM utiliza uma hipótese de segmentação que ainda precisa ser validada, e o SOM representa uma meta inicial, não uma previsão de participação de mercado.

## Hipóteses do MVP

O desenvolvimento foi orientado pelas seguintes hipóteses:

1. Praticantes de atividades físicas possuem interesse em participar de uma comunidade esportiva.
2. Usuários demonstram interesse em compartilhar suas atividades e conquistas.
3. A interação com publicações de outros praticantes pode aumentar o engajamento.
4. A possibilidade de acompanhar diferentes modalidades em um único ambiente pode tornar a plataforma mais atrativa.
5. Uma experiência gratuita pode facilitar a adesão inicial de usuários.

Essas hipóteses ainda precisam ser testadas com usuários reais.

## Funcionalidades propostas

O escopo planejado para o MVP contempla:

- Autenticação e cadastro de usuários.
- Perfil esportivo.
- Feed da comunidade.
- Compartilhamento de atividades.
- Registro de atividades físicas.
- Curtidas e comentários.
- Histórico de atividades.
- Área administrativa para gerenciamento e moderação.

A disponibilidade e o funcionamento de cada recurso devem ser considerados conforme a implementação efetivamente entregue.

- **Lovable Cloud:** infraestrutura de backend, autenticação e persistência de dados, conforme os recursos utilizados no projeto.

## Mega prompt utilizado

O desenvolvimento foi orientado por um prompt que estabeleceu os seguintes requisitos:

- Criar uma comunidade esportiva com identidade visual própria.
- Utilizar tema escuro, tons de grafite e verde vibrante.
- Desenvolver uma interface responsiva para desktop e dispositivos móveis.
- Estruturar autenticação, feed, registro de atividades e perfil esportivo.
- Prever uma área administrativa com controle de permissões.
- Utilizar o Lovable Cloud como infraestrutura do projeto.
- Priorizar organização, usabilidade, validação de formulários e segurança.
- Manter o escopo limitado às funcionalidades essenciais do MVP.

O prompt completo foi utilizado como especificação inicial para orientar a construção da aplicação.

## Limitações e melhorias futuras

Por se tratar de um MVP, existem oportunidades de evolução:

- Validar a proposta com praticantes de diferentes modalidades.
- Aprimorar a experiência de interação entre usuários.
- Implementar desafios e rankings esportivos.
- Adicionar integração com dispositivos vestíveis.
- Desenvolver estatísticas mais avançadas.
- Explorar modelos de monetização após validar a demanda.

## Processo de desenvolvimento

O projeto foi desenvolvido com apoio do ChatGPT na definição da proposta de valor, identificação do problema, estruturação do mercado, elaboração do Business Model Canvas e criação da especificação utilizada no Lovable.

O Lovable foi utilizado para gerar a aplicação, enquanto o GitHub foi utilizado para armazenar e versionar o código-fonte.
